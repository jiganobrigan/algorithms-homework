1.1. Что такое граф?

Граф представляет собой структуру, которая описывает отношения между различными объектами. Он состоит из вершин и соединяющих их рёбер.

Примеры использования графов:

 Построение транспортных маршрутов.
 Представление связей пользователей.
 Организация сетевых соединений.
 Моделирование различных процессов

1.2. Ориентированные графы

Ориентированный граф - это разновидность графа, в котором связи между вершинами имеют заданное направление.

Это означает, что переход от одной вершины к другой может быть возможен только в одну сторону.

Примеры применения:

 Система переходов между страницами сайта.
Последовательность выполнения операций.
Связи между зависимыми задачами.

1.3. Графы с весами

Взвешенный граф - это граф, в котором каждому ребру назначается определённое значение, называемое весом.

Вес используется для обозначения различных характеристик связи.

Например:

Протяжённость маршрута.
Время прохождения пути.
Финансовые расходы.
Затраты ресурсов.

С помощью взвешенных графов можно определять наиболее эффективные варианты перемещения или выполнения задач.

1.4. Обход графа в ширину (BFS)

BFS (Breadth-First Search) - алгоритм, предназначенный для обхода вершин графа в порядке увеличения расстояния от начальной вершины.

В первую очередь проверяются соседние вершины, затем вершины следующего уровня.

Особенности BFS:

 Основан на использовании очереди.
 Проверяет вершины последовательно по уровням.
Находит кратчайший путь в невзвешенном графе.
Позволяет определить, существует ли путь между вершинами.

2. Основы работы с Git

2.1. Назначение Git

Git - это распределённая система контроля версий, которая используется для управления файлами и отслеживания истории разработки.

Git позволяет:

1. Записывать историю изменений.
2. Сравнивать разные версии файлов.
3. Возвращаться к ранее сохранённым состояниям проекта.
4. Работать над одним проектом нескольким разработчикам.
5. Создавать отдельные направления разработки.
6. Объединять изменения в общую версию проекта.

2.2. Понятие веток и коммитов

Ветки (Branches) - это отдельные направления работы над проектом. Они дают возможность разрабатывать новые функции независимо от основной версии программы.

Примеры веток:

 main - основная версия проекта.
 test - ветка для проверки изменений.
feature - разработка новых возможностей.

Коммиты (Commits) - это сохранённые контрольные точки проекта, которые фиксируют внесённые изменения.

Пример создания коммита:

git add .
git commit -m "Изменение файлов проекта"

3. Команды для работы с Git

Создать новый репозиторий:

git init

Подготовить файлы к сохранению:

git add .

Зафиксировать изменения:

git commit -m "Сохранение изменений"

Посмотреть список веток:

git branch

Создать новую ветку:

git switch -c test

Отправить изменения в удалённый репозиторий:

git push

Получить последние изменения:

git pull

4. Итог

Графы помогают описывать отношения между объектами и решать задачи, связанные с поиском путей и анализом связей.

Алгоритм BFS позволяет выполнять обход графа по уровням и находить кратчайший путь в невзвешенных графах.

Git необходим для удобного управления программными проектами, сохранения истории изменений и совместной разработки.

Изучение этих инструментов является важным этапом освоения программирования.
